#  Основы командной строки
`echo` - показывает, что внутри файла  
`pwd` - print working directory  
`ls`-показывает список файлов в текущей директории  
`cd`- change directory  

Есть два способа обозначить путь до файла:  
Абсолютный -первым символом в пути идет `/`  
Относительный - во всех остальных случаях. Берет текущую рабочую директорию и присоединяет к ней "Music".  

`cd ..` - перейти в директорию уровнем выше  
`cd ../..` - выходим на 2 уровня вверх  
`cd` без аргументов - переход в домашнюю директорию  
`~` (тильда) - специальное обозначение домашней директории. Из любого места набираем:  
`cd ~/Music` - перейдем в директорию home/music  
`ls Music` - ls принимает аргумент который нужно проанализировать  
`cd -` - переход в предыдущую директорию. Не на уровень ниже, а просто предыдущую.  

## Аргументы и опции

`ls -a` - показывает скрытые файлы  
`ls Public` - показывает содержимое папки Public  
В данном случае Public это аргумент, а `-a` это опция.  
`ls -l` - выводит доп информацию по каждому файлу.  
`ls -a -l` ИЛИ `ls -al` ИЛИ `ls -la` - также мы можем использовать опции и аргументы одновременно: `ls -la Music`.  
Обычно опции указываются слева от аргументов, но бывает и наоборот.  
Посмотреть подсказку можно используя команду `man` (manual). `man <имя команды>`.  
Перемотать вперед f(forward) и назад(backward).  
У опций есть длинная версия, а есть короткая.  
`-v` или `--version` это одно и тоже.  
Как правило короткие версии используются в терминале, а длинные в скриптах для наглядности.  

## Файловая структура

stat ~/.profile - покажет информацию о любом файле/директории  
В unix файлы и директории *регистрозависимые*.  
В unix системах все является файлами. Даже директория это файл который содержит список файлов.  
В unix есть FHS - базовый стандартизированный набор каталогов. За каждым закреплена особая роль.  
/etc - содержит конфигурации программ в обычных файлах.  
/home - содержит домашние директории пользователей системы, за исключением суперпользователя root, его домашний каталог находится по адреу /root.  
Также существуюи скрытые файлы, их можно увидеть с помощью `ls -a`.  
Кроме того бывают еще такие типы файлов:  
Hard link - дополнительное имя для уже существующих файлов.  
Symbolie link - символическая ссылка, аналог ярлыка в Windows. Если удалить файл, то ссылка будет вести в никуда.  
Socket - специальный файл, через который происходит взаимодействие между разными процессами ОС.  
`.` (точка) - обозначает текущую директорию  
`..` (две точки) - обозначает родительскую директорию  

## Чтение файлов

`cat` - читает файлы. Ей обязательно нужен аргумент в виде файла.  
Иногда нужно посмотреть только начало файла или его конец, для этого есть команды: `head` и `tail`, Например:  
`head -n 2 .profile`  
`tail -n 2 .profile`  
Опция `-n` - нужна, чтобы задать желаемое количество строк.  
Например, чтобы читать логи все вышеперечисленное не подойдет, нужно чтобы появлялись новые строки в выводе. Для этого есть специальный флаг:  
`tail -f path/to/file` - выводит последние строки, но и ждет появления новых.  
Среди примеров это первая команда которая *захватывает управление*. Т. е. она не заканчивает выполнение сразу, а продолжает работать, ожидая новые данные.  
Для остановки этой команды нужно нажать *CTRL + C*.  

## Пейджеры

Самый распространенный называется `less`.  
Пейджеры отличаются тем, что одинаково хорошо работают с любым размером файла. Они загружают в память только ту часть файла которая помещается на экране.  
Пейджер `less` команды:  
Выход - `q`  
Вперед на страницу - `f`  
Назад на страницу - `b`  
Поиск текста - вводим `/`, печатаем текст и enter  
Переход к следующему совпадению - `n`  
Переход к предыдущему совпадению - `N`  

## GREP

`grep` (Global regular expression print) - поиск определенного текста по файлу или файлам.  
`grep [options] PATTERN [FILE]`  
PATTERN - то, что хотим найти    
FILE - путь до файла в котором нужно искать.  
Количество отображаемых строк *до* искомой строки: `-B` или `--before-context`  
Количество отображаемых строк *после* искомой строки: `-A` или `--after-context`  
Количество отображаемых строк *до* и *после* искомой строки: `-C` или `--context`  
`grep -C 1 PATH .profile` - для каждоый найденной строки будет выведена одна строка выше и ниже.  
Иногда мы не знаем в каком файле находится то, что нам нужно.  
В такой ситуации нужно сделать 2 изменения:  
1. Добавить опцию `-r` - она указывает, что нужно искать внутри директории. Ищет рекурсивно, т.е. с включением всех поддиректорий.
2. Указать путь до директории, а не файла.  
`grep -r PATH`  
Если добавить опцию `-n`, то отобразиться номер строки.  

## Редактирование файлов

Nano - простой редактор типа блокнота.  
Vim - более мощный редактор с режимами работы.  
В начале Vim запускается в режиме *COMMAND*.  
Обычное редактирование текста можно начать нажав `i`. Тогда мы перейдем в режим *INSERT*. Для выхода в режим команд можно нажать `ECS` или *CTRL + [*.  
Всего есть 4 режима работа:  
- Командный режим - режим по умолчанию. В нем можно перемещатсья по файлу, вносить изменения с помощью комбинаций клавиш, удалть и искать текст
- Режим вставки - обычный режим ввода с клавиатуры
- Визуальный режим - выделение произвольных участков текста
- Режим командной строки - собственная командная строка для редактирования текста, из которой можно выполнять множество разнообразных команд.  

Выйти из Vim: войти в командный режим нажав `ESC` или *CTRL + [*. Затем набрать `:` (двоеточие) и ввести `q!` и нажать enter. Чтобы выйти с сохранением вводим `:wq!`.  

## Потоки

При старте любой программы ОС связывает с ней 3 потока:  
- STDIN (standart input)
- STDOUT (standart output)
- STDERR (standart error)  
Для языка программирования эти потоки выглядят, как файлы и взаимодействие с ними проиходит, как с файлами.  
ОС позволяет подменять потоки, например:  
`ls -la > output` - ответ выйдет не на экран, а в файл output. Это называется *перенаправление потоков*.  
Символ `>` означает, что мы берем команду слева и выводим в файл справа. Этот символ всегда *перезаписывает файл*.  
Работает это абсолютно с любой командой которая выводит результаты своей работы в консоль.  
Если нужно не перезаписать, а *добавить*, то используется `>>`.  
Для экспериментов удобно использовать команду `echo`, она принимает на вход строчку и выдает ее в STDOUT.  
STDIN работает наоборот, через него программа может получать данные на вход.  
Существует команда `wc`. Она умеет считать количество слов, строк, символов в файле.  
Когда говорим о файле, то в nix системах это почти всегда означает, что данные можно передать и в стандарттный поток ввода.  
`wc -l < result` - содержимое файла result отправляем в стандартный ввод.  
`wc -l < result > output` - содержимое файла result отправляем в стандартный ввод команды `wc`, а вывод отправляем в output.  
STDERR позволяет отделить нормальный вывод программы от возникающих ошибок.  
Если попробовать отобразить содержимое несуществующий директории, то команда `ls` выдаст ошибку.  
Если попробуем перенаправить вывод в файл, то он останется пустым.  

### Перенаправление STDERR в STDOUT

За каждым потоком закреплен номер, это называется файловый дескриптор.  
- STDIN - 0
- STDOUT -1 
- STDERR -2  
Первый способ - перенаправить STDERR в STDOUT и отправить оба потока в файл.  
`ls -la > output 2>&1`  
Символ `&` нужно ставить, чтобы указать поток, в который осуществляется перенаправление.  
Пененаправление конкретного потока в файл. Нужно указать его номер перед `>`:  
`cd lala 2> output`  
Перенаправление обоих потоков в файл. Этот вариант используется чаще всего при отладке:  
`cd lala &> output`  

## Пайплайны

Благодаря пайплайну можно соединять программы и перетаскивать данные сквозь них.  
Получается цепочка функций, в которой каждое звено выступает в роли преобразователя или фильтра.  
`grep PATH .profile | grep local`  
Символ `|` - и называется пайп.  
Эту записать можно изменить, использу перенаправление. Так она станет проще для модификации.  
`cat .profile | grep PATH | grep local`  
Еще пример:  
`cat source | grep Dog | uniq | sort`  
1. Читает файл source
2. Грепает входные данные по строке "Dog"
3. Убираются дубли (`uniq`)
4. Сортируются входные данные и выводятся на экран  

## Манипулирование файловой структурой

Основные команды:  
`touch` - создает файл. Основная задача этой утилиты поменять время последнего доступа к файлу. Но она обладает побочным эффектом - если файла не существует, то он будет создан.  
`rm` - удалить файл  
В nix системах нет понятия переименовать файл, это всегда равносильно перемещению  
`mv` - переместить файл  
`mv file renamed-file`  
`cp` - утилита копирования файла  
`cp file file-copy`  
`-r` (recursive) - свойство для копирования директории  
`mkdir` (make directory) - создание директории  
`mkdir -p one/two/three`. Флаг `-p` (`--parents`) создает директории рекурсивно  
Удаление директории происходит, как и с файлами, но нужен флаг `-r`  
`rm -r my-dir`  
Есть еще флаг `-f` (force), чтобы система не задавала вопросов по каждому файлу и молча удалила всё  
`rm -rf one`.
